
# 无翼守护 / WuYiGuard

一个运行在 Android 设备本地的**屏幕文字监测与自动清理加速工具**。

当设定的特征文字出现在屏幕上，或屏幕持续处于全黑 / 全白状态超过设定时长时，
应用会自动执行：**回到系统桌面 → 打开最近任务 → 点击系统「清除全部」**，
从而释放后台占用的内存，让设备保持流畅。

> **本应用不联网、无服务器、不收集任何数据。** 详见 [隐私政策](PRIVACY.md)。

## 适用系统

Android 9.0（API 28）及以上，包括部分 HarmonyOS 5 以下兼容 Android 的系统。

## 主要功能

| 功能 | 说明 |
|---|---|
| **条件一 · 文字触发** | 对屏幕做本地文字识别，命中关键词后触发清理 |
| **条件二 · 黑白屏触发** | 屏幕平均亮度持续低于/高于阈值超过设定时长后触发清理 |
| **触发后动作** | 回系统桌面 → 打开最近任务 → 点击「清除全部」 |
| **悬浮窗控制** | 可拖动的悬浮面板，两个开关独立控制；点「—」或空白区域缩小 |
| **双通道取画面** | Android 14+ 用无障碍截图避免被系统录屏抢占；低版本用系统屏幕采集 |
| **本地日志** | 运行日志与触发记录写入设备本地，可查看、可导出 |
| **机型适配工具** | 内置节点树导出，用于适配清除按钮是纯图标的 ROM |

## 需要授予的权限

| 权限 | 用途 | 是否必需 |
|---|---|---|
| 无障碍服务 | 回系统桌面、打开最近任务、点击系统清除按钮；部分机型读取窗口文字 | **必需** |
| 悬浮窗（显示在应用上层） | 显示悬浮控制面板 | **必需** |
| 屏幕采集（仅 Android 9/10） | 获取屏幕画面用于识别 | 低版本必需 |
| 电池优化白名单 | 避免后台被系统杀掉 | 建议 |
| 通知 | 前台服务的常驻通知 | Android 13+ 建议 |

**我们不使用无障碍权限向任何第三方应用注入点击、滑动或按键。**
详见 [隐私政策 · 无障碍权限专项说明](PRIVACY.md#四无障碍权限专项说明)。

## 快速开始

1. 安装 APK，打开应用，阅读并关闭公告
2. 在主界面依次授权：无障碍 → 悬浮窗 → 电池优化白名单
3. 点「开启屏幕监测」（Android 9/10 会弹出系统屏幕采集确认框）
4. 打开「拿翼保护」/「过图保护」开关
5. 打开悬浮窗，即可在其他应用上方随时开关功能

## 关于本工具的定位

本工具是一个**自动化清理加速器**：

> **看屏幕**（系统接口获取画面）→ **本地识别**（设备端 OCR / 窗口文字）→
> **回桌面 + 清后台**（系统级操作）

它只做三件系统层面的事：读取屏幕、识别文字、清理后台。
不涉及任何第三方应用的内部逻辑，不读取也不修改任何应用的数据，
不会代替用户操作任何应用。详见 [隐私政策 · 与外挂/作弊工具的界限](PRIVACY.md#五与外挂--作弊工具的界限)。
